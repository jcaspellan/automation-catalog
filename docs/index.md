# Azure Automation Catalog

Welcome to my automation catalog.

This site showcases reusable Azure automation assets designed for cloud operations, governance, reporting, and remediation.

## What Makes This Catalog Different

Each automation is presented as a reusable solution with two delivery models:

| Delivery Model | Purpose |
|---|---|
| Azure Automation Runbook | Production-ready, scheduled, managed Azure execution |
| Local Script | Portable execution for validation, debugging, and ad hoc operations |
